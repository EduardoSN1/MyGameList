# MyGameList

A ideia do nome é representar uma lista pessoal onde o usuário pode colocar e organizar
seus jogos.
A identidade visual terá um estilo mais voltado para jogos, utilizando um fundo escuro e
cores mais fortes para destacar algumas informações

As principais funções serão:
1. Adicionar um jogo;
2. Editar um jogo;
3. Excluir um jogo;
4. Alterar o status do jogo;
5. Dar uma nota para o jogo;
6. Adicionar tags;
7. Escolher a plataforma;
8. Pesquisar jogos;
9. Filtrar os jogos;
10. Visualizar todos os jogos cadastrados.
